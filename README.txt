mcwallet PWA demo

Это учебный интерфейс: все балансы и операции вымышлены.
Не вводите настоящие банковские данные, пароли или персональную информацию.
Реальные платежи, карты, криптовалюта и банковские подключения отсутствуют.

Как открыть на iPhone:
1. Разместите содержимое этой папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте опубликованный адрес в Safari.
3. Нажмите «Поделиться» -> «На экран Домой» -> «Добавить».

Важно: ZIP сам по себе не устанавливает приложение на iPhone. Для PWA нужен опубликованный HTTPS-адрес.
Для локального просмотра можно открыть index.html, но установка и офлайн-режим требуют размещения на HTTPS-сайте.
