mcwallet 5.0 — интерактивный демо-прототип.
Загрузка: разместите все файлы в корне HTTPS-хостинга (например GitHub Pages).
Откройте сайт в Safari и выберите Поделиться -> На экран Домой.

Важно: регистрация и вход работают только локально в браузере этого устройства.
Логины и демо-пароли хранятся в localStorage без серверной защиты. Не используйте настоящие пароли, email, банковские данные или личную информацию. Это не настоящий финансовый сервис, карты и операции вымышленные.
